# Get example exon annotations for mus musculus (mm10)

This is a small subset of the exons returned by
[`get_exons_mus_musculus()`](https://shians.github.io/NanoMethViz/reference/get_exons_mus_musculus.md)
for demonstrative purposes. It contains the exons for the genes Brca1,
Brca2, Impact, Meg3, Peg3 and Xist.

## Usage

``` r
get_example_exons_mus_musculus()
```

## Value

data.frame containing exons

## Examples

``` r
example_exons <- get_example_exons_mus_musculus()
```
