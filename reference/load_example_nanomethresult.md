# Load an example NanoMethResult object

Load an example NanoMethResult object for demonstration of plotting
functions. Run `load_example_nanomethresult` without the function call
to see how the object is constructed.

## Usage

``` r
load_example_nanomethresult()
```

## Value

a NanoMethResult object

## Examples

``` r
nmr <- load_example_nanomethresult()
#> Successfully matched 6 samples between data and annotation.
```
